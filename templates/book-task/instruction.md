# 高压缩整书认知重构

阅读 `/app/source/` 中提供的完整书稿，在 `/app/submission.md` 写出一篇独立成文的中文重构文章。

你的任务不是逐章摘要、观点罗列或主题介绍，而是在有限篇幅内重建作者形成判断时使用的认知结构。文章应使没有读过原书的读者能够理解：

- 作者试图解决的核心问题；
- 主要判断及其关键推理路径；
- 决定结论成立的概念区分、条件和边界；
- 作者提出、暂时考察、部分承认或反驳了哪些观点；
- 对论证具有构成作用的案例、实验、反例或思想材料，以及它们发挥了什么作用。

允许重新组织表达顺序，也不要求复述原书措辞。只要不改变读者对作者立场、推理方向、适用条件和论证功能的理解，可以采用适合本书的文体和结构。纯说明性的例子可以替换；参与作者结论形成的关键材料不得被普通例子或领域常识取代。

## 交付要求

- 输出文件：`/app/submission.md`
- 目标篇幅：`{{MIN_CHARS}}–{{MAX_CHARS}}` 个中文字符；实例化任务时必须替换该占位符。
- 文章必须独立可读，不得提及评分规则、金标准或裁判过程。
- 不得以目录、逐章摘要、要点清单代替完整文章。
- 不得只给出最终结论而省略决定该结论的核心推理。
- 不得大段照抄原书；必要的短语引用应克制使用。
