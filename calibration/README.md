# Calibration

校准集检验评分系统能否识别预先定义的结构损伤。它不等于正式模型样本，也不证明 Judge 拥有普遍文学审美。

推荐目录：

```text
calibration/
├── global/
│   ├── cases.jsonl
│   └── expected.jsonl
└── books/
    └── <book-id>/
        ├── cases.jsonl
        └── expected.jsonl
```

每个变体必须记录：

- 原始文本或基准文本 ID；
- 只改变了什么；
- 哪些关系标签应变化；
- 哪些关系不应变化；
- 哪些路径应从完整变为不完整；
- 人工确认人；
- Book Card、Locator、Judge Prompt 和模型版本。

由 AI 生成的扰动仍需 Benchmark 作者确认它只改变目标变量。

## 最低覆盖类型

1. 语义保持改写；
2. 不改变认知功能的正确重组；
3. 只保留最终结论；
4. 删除一条核心关系；
5. 删除构成性案例；
6. 删除普通说明例；
7. 常识替换；
8. 术语堆砌；
9. 删除限定；
10. 关系反转；
11. 把对手观点写成作者观点；
12. 改变认知功能的错误重排；
13. 漂亮空话。

## 预期行为

| 变体 | 关系覆盖 | 路径完整 |
|---|---|---|
| 语义保持改写 | 基本不变 | 不变 |
| 正确重组 | 基本不变 | 不变 |
| 只保留结论 | 仅终点相关局部可能出现 | 核心路径失败 |
| 删除核心关系 | 对应叶子失败 | 所属必需路径失败 |
| 删除构成性案例 | 案例相关关系失败 | 相关路径失败 |
| 删除说明性案例 | 机制已明确时原则上不变 | 不变 |
| 常识替换 | 书特异关系失败 | 路径失败 |
| 删除限定 | 边界关系失败 | 依赖该边界的路径失败 |
| 关系反转 | 对应关系失败 | 路径失败 |
| 立场误认 | 立场相关关系失败 | 路径失败 |
| 错误重排 | 仅在改变认知功能时失败 | 视损伤而定 |

## 冻结纪律

开发书可用于反复修改 Rubric、Locator 和 Judge。

保留书的：

- 公开 instruction；
- Book Card；
- Oracle；
- 校准文本；
- 预期关系标签；
- 预期路径状态；

必须在正式模型输出产生前冻结。

不要只报告总体准确率。至少报告：

- false positive；
- false negative；
- 关系反转识别；
- 立场误认识别；
- 构成性案例删除识别；
- 说明性案例删除的不变性；
- 语义保持改写一致性；
- 路径完整识别；
- 重复 Judge 或多 Judge 分歧率。

关键关系反转、立场误认或构成性案例删除仍被判为完整通过时，不得冻结该书任务。
