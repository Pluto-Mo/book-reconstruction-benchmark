## 已做语义抽查

已回看当前工作锚中的以下高风险结构：大众欲望的“既存而非创造”、读者认知与市场熟化的分离、认同的角色表达及既有形象桥、渐进式接受链、重新界定的视角重排、集中比较的三段因果链、外部证明 / 机制说明 / 验证安排的区分，以及终章对固定公式的再次否定。

Oracle 已按 60 条关系、16 条必经路径与 19 条开发篇章边反向定位。第一次独立盲审发现“承诺与机制耗竭→第五种认知难题→功能/角色双重购买理由”之间少了一座桥，随后补齐。全中文改写后的第二次独立盲审又发现第四阶段遗漏“竞争者的新机制”这一条件，并标出三句审计者旁白；四处均已定向修正。Human Owner 随后澄清作者口吻不评分、不作 Judge 参照，Oracle 因而只在编辑层面改成更接近原作者自然提问、解释和回收论点的声音，去掉连续命令句。改写后的第三次独立语义审计确认关系、路径和篇章边仍为 `60/60`、`16/16`、`19/19`，四个构成性案例及历史主张归属均未受损。

## 尚未解除的风险

1. OCR 版本存在断字、漏章题和关键术语误译；冻结前须用可靠原版逐点核对高权重关系。可靠性政策按书制定、与来源语言无关。
2. 四个构成性案例已获暂定批准并配有整案删除样本，但尚未由生产 Judge 验证是否能稳定识别各自的精确损伤范围。
3. 五版 reference 可达性曲线到 3,000 上限仍未出现覆盖断点；这只能证明人工参考答案可达，不能说明被评 Agent、Locator 或 Judge 在短篇幅下仍稳定。正式篇幅须等待同构 Agent trial 的真实损失曲线。
4. 八个一级结构暂时等权；虽已有正向锚和首批单变量破坏样本，样本类型与 Judge 重复运行仍不足以支持权重校准。
5. 历史广告中的医学、烟草、性别与竞争性主张须保持作者归属，避免被评分器误当作基准认可的事实或价值立场。
6. 当前 22-edge 边池和 19-edge 单面板已通过 Oracle 可达性、十六份负向扰动和一份正确重组对照的预期边界审计，但尚未通过生产 Judge 的成本、重复一致性和实际分辨率测试。
7. 24-code-point 精确片段扫描没有命中不等于不存在更短或非逐字的来源依赖；冻结前仍需人工检查转述独立性与必要的来源归属。
