# 《突破性广告》长度保留曲线（reference draft）

## 先给结论

这五个版本尚未显示认知结构的断点。无篇幅限制、八千、六千、四千和三千五个条件，在当前 draft 金卡上都能明确恢复 `60/60` 条认知关系、`16/16` 条必经路径、`19/19` 条开发面板边和 `4/4` 个构成性案例。

这不是说三千一定适合正式主榜。它只说明：对这本书的人工参考答案而言，三千上限仍有完整表达的可达解。真正用于选定主榜篇幅的分辨率，必须来自被评 Agent 在相同条件下的实际损失曲线与编辑连贯性 Judge；当前生产 Judge 尚未实现，因此不能冻结 `L-main`。

## 曲线怎样解释

1. `L-8000` 和无篇幅稿都没有消耗完整预算，主要证明语义保持改写的可达性，不构成压缩极限证据。
2. `L-6000` 已比不限篇幅稿短约四成，仍能保持解释、案例和回环；六千上限没有产生可观测的结构损失。
3. `L-4000` 与 `L-3000` 的信息密度明显上升。两版初审都暴露了“桥接条件被压成结果”的风险：四千稿曾省略认知变化使旧标题失效的明确因果，三千稿曾省略药味与清洁力不可分的案例前提。定点补回后才恢复满覆盖。
4. 因此当前最有价值的信号不是平坦的满分线，而是短稿更容易漏掉条件、限定和不可替代案例的内部因果。正式 Judge 必须能区分“提到结论”与“保留桥”。
5. 作者口吻只用于把参考稿编辑成自然文章；不进入覆盖率、不作为 Judge 参照，也不能用来惩罚语义正确的不同表达方式。

## 对 Benchmark 规模的含义

长度是开发实验变量，不增加 Harbor 的内容 Task 数。当前只在这一开发书上形成五个条件；正式不超过十五本书的主榜仍应每书冻结一个窄篇幅区间。若把五档全部扩到十五本、每书三次 rollout，单模型会从 45 个 Agent trials 增至 225 个，收益不足以抵消成本。

下一阶段先对这一开发书的五个 instruction 条件各跑少量同构 Agent trial，保持模型、脚手架、工具、时限、卡片、面板、Probe 和 Judge 不变。只有篇幅句允许变化。观察实际模型在哪一档开始丢关系、断路径或破坏文章组织，再把重复 rollout 集中到转折点附近；正式 `L-main` 在查看保留书结果以前冻结。

机器可读记录位于 `length_runs.draft.jsonl`，各稿的逐版审计历史位于对应的 `oracle_*.trace.md`。
