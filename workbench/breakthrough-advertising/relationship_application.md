# 关系、路径和篇章边如何进入 Oracle

## 一、先分清三层东西

这套 Rubric 不是把六十个知识点塞进文章，而是用三层约束共同控制成文。

| 层级 | 控制什么 | 在文章里怎样出现 |
|---|---|---|
| 认知关系 | 两个或多个命题之间究竟是什么关系，以及方向、条件、边界和立场归谁 | 写成一句或一组可以独立判断真假的论证，不显示内部编号 |
| 必经路径 | 若干认知关系必须按什么依赖链共同成立 | 写成读者能够顺着走完的推理，不能只保留起点和结论 |
| 篇章边 | 相隔较远的段落为什么以这个次序出现，以及前段怎样改变后段的意义 | 通过铺垫、转折、案例回收、反驳、综合和首尾回环体现 |

所以，“应用关系边”不等于在一段里提到两个概念。真正的应用是：前一个内容必须为后一个内容提供前提、限制、问题、反驳对象或证明需要；交换次序以后，文章的论证功能会受损。

## 二、认知关系怎样变成一条论证

以第一部分为例，文章没有依次定义“大众欲望、产品表现、主题”，而是把六条关系连成一条因果链：

```text
广告不能创造大众欲望
→ 因此只能发现、聚焦并导流既有欲望
→ 迫切度、持续性、覆盖面共同选出一个主导欲望
→ 产品的物理事实只能支撑功能表现
→ 只让最能接上主导欲望的一项表现居前
→ 主导欲望与主导满足方式共同形成主题
```

这条链落在 Oracle 第 9—15 行。任何一环被删掉，意思都会改变：没有能力边界，“选择欲望”会退化成市场研究清单；没有物理事实与功能表现的从属关系，“主题”会退化成卖点汇总；没有一主一从的取舍，文章会变成利益清单。

认知关系还控制立场。例如“广告可以凭空制造欲望”是被反驳的观点，所以正文必须写成“无法、不能”，不能中性并列；电视、香皂和汽车装置的功效来自历史广告主张，所以正文必须写成“广告提出的主张”，不能替基准把它宣布为客观事实。

## 三、必经路径为什么不能只剩摘要

《电视维修手册》是最清楚的一条必经路径：

```text
共同的不满与症状认同
→ 电视总体可靠
→ 普通人可以处理一部分外部小调整
→ 购买知识、减少维修依赖并节省费用
```

这不是四个都出现就算通过。第二步必须准备第三步，第三步必须准备经济回报，次序不能反转。因此 Oracle 第 59—61 行不仅复述案例，还明说“改变顺序，就改变整个论证”。这就是路径约束在文章中的形态。

同一案例到第 63 行又被重新使用：第一次证明的是“怎样安排事实使结论逐步被接受”，第二次证明的是“怎样在不改变事实时重排看待事实的角度”。这种回收同时保留了“渐进式接受”和“重新界定”的区别，避免把二者混成同一种说服技巧。

## 四、十九条开发篇章边怎样控制文章

下面不是覆盖清单，而是每条边在成文里实际承担的工作。

| 篇章边 | Oracle 位置 | 对成文施加的控制 |
|---|---:|---|
| AE-001 | 第 3—5 行 → 第 15—19、101—105 行 | 开篇“旧公式不能解决新问题”先控制主题与入口的分析，结尾再回收为“每个问题要求不同结构”。 |
| AE-002 | 第 9 行 → 第 11—15 行 | “不能创造欲望”的能力边界，迫使后文改为选择、聚焦和导流欲望。 |
| AE-003 | 第 15 行 → 第 19—23 行 | 先决定主题卖什么，再由读者认知和市场熟化决定从哪里进入；标题不能反过来重新发明卖点。 |
| AE-004 | 第 21 行 → 第 23 行 | “标题通常只赢得下一句”的一般边界，在最难读者那里展开为认同→问题→解决方向→产品。 |
| AE-005 | 第 25 行 → 第 27 行 | 承诺扩大到失信以后，文章才从“能给什么”转向“为什么能做到”；机制耗损后再转向认同。 |
| AE-006 | 第 27—29 行 → 第 43 行 | 承诺和机制都失去入口能力，才需要先让读者认出自己；后文再展开功能价值与角色价值。 |
| AE-007 | 第 21 行 → 第 31—33 行 | 标题把读者交给正文，正文接手并用欲望、认同、信念形成确信。 |
| AE-009 | 第 43 行 → 第 45 行 | 角色价值不是任意想象；它立即受到市场既有产品形象的约束。 |
| AE-010 | 第 45 行 → 第 47—49 行 | 先提出不能直接换人格，再用切斯特菲尔德完成“保留旧形象—降强度—搭桥—新角色”的反驳，并加上两道可信度检查。 |
| AE-011 | 第 55 行 → 第 57 行 | “短时广告不能正面重造信念”的边界，下游转成事实准备、位置和接受顺序。 |
| AE-012 | 第 59—61 行 | 电视案例不是故事；案例的不可逆顺序被抽象成延迟结论和逐层取得同意的原则。 |
| AE-013 | 第 59—61 行 → 第 63 行 | 同一电视材料第一次处理接受次序，第二次转而处理事实分类和视角重排。 |
| AE-014 | 第 63—67 行 | 救生圈香皂保留药味事实、只改变它的意义，从而界定重新描述不等于遮掩。 |
| AE-015 | 第 27—29 行 → 第 71—73 行 | 前面的市场熟化诊断，决定后面机制只能在读者追问原因时进入，并决定命名、描述或前置主打。 |
| AE-017 | 第 75 行 | “只攻击竞争者会引起怀疑”直接推出弱点→顾客损害→本品对应补救的比较链。 |
| AE-018 | 第 77 行 → 第 79、89—91 行 | 火焰喷射器先用逐点比较制造证明需要，空军权威随后进入，两者再被回收为相互强化。 |
| AE-019 | 第 55—57 行 → 第 87—89 行 | 前面关于信念准备和位置的原则，到后面兑现为“外部证明必须等读者主动需要时再出现”。 |
| AE-021 | 第 3—5 行 → 第 101—105 行 | 开篇反公式不是一次性口号；结尾用结构会改变同一内容的力量完成回环。 |
| AE-022 | 第 33 行 → 第 93—97 行 | 欲望、认同、信念先为分析而拆开，终章必须重新交织成从注意到确信的整体。 |

## 五、为什么不能把关系边直接露在文章表面

如果正文写成“第一条关系是……第二条关系是……”，它也许容易核对，却不再是重构文章。现在的处理是：

1. 编号只留在隐藏 trace 中；
2. 认知关系进入句子内部，控制因果、先后、条件、反驳和限定；
3. 必经路径控制连续推理，禁止只写起点和终点；
4. 篇章边控制段落之间的远距离依赖，尤其是案例回收和首尾回环；
5. Judge 最后反向重构候选文章表达了哪些关系，而不是要求候选文章复述 Rubric 的术语。

这也是为什么同样覆盖六十条关系，仍可能写出两种质量完全不同的文章：一篇只是把概念装进八个篮子，另一篇让前一段真正改变后一段为什么出现、何时出现以及读者怎样理解它。篇章边测的正是这个差别。
