# Benchmark V1：基准问题

## 1. 要测量什么

给定一本完整的非虚构作品和固定篇幅，模型能否在高压缩重构中保留该书真正具有区分力的认知结构，而不是把它压缩成正确、流畅、但无信息量的领域常识。

这里的“认知结构”不是关键词覆盖率，也不是一组彼此独立的观点。它是由命题节点、有方向关系和核心路径组成的图，包括：

- 作者试图解决的问题；
- 因果、支持、反驳、区分、条件、边界和推论；
- 作者观点、对手观点、暂时假设、让步和否定之间的立场差异；
- 构成结论所必需的案例、实验、反例或思想材料；
- 这些内容如何共同推进到作者的判断。

详细表示规则见 [认知结构 Rubric 契约](cognitive-structure-contract.md)。

## 2. V1 评分对象

V1 不再把“作者性组织”作为一个与认知结构分离的模糊维度。

判断原则是：

> 如果一种组织、顺序、让步或反驳方式会改变读者对作者立场、推理方向、条件边界或论证功能的理解，它就是认知结构的一部分；如果只是句式、节奏或修辞风格，则暂不进入主分。

当前 Pilot 先报告三个字段：

| 指标 | 含义 | 当前状态 |
|---|---|---|
| `cognitive_relation_coverage` | 书特异关系叶子的加权覆盖 | Pilot 主指标 |
| `complete_core_path_rate` | 必需认知路径完整通过的结构比例 | 与覆盖分并列报告 |
| `hard_constraints` | 字数、文件、格式、任务完成与复制率等程序检查 | 独立报告 |

“抵抗常识化与空洞化”不再简单作为一个凭印象打分的独立 10% 项。它主要通过以下可观察失败体现：

- 只保留主题词，没有保留关系；
- 只保留最终结论，没有保留推理路径；
- 用领域常识替代书特异机制、限定或反驳；
- 把构成性案例降格为装饰性故事；
- 把作者正在反驳的观点写成作者主张。

这些失败进入具体关系的 `fail_if`、常见假阳性和校准集，并可额外报告 `genericity_failure_rate` 作为诊断。

最终单一 `reward` 的组合公式尚未冻结。开发阶段若 Harbor 必须接收一个标量，可暂时令 `reward = cognitive_relation_coverage`，但必须同时保存完整路径率，且不得把这一临时兼容值当作最终排行榜定义。

## 3. 公开任务与隐藏 Rubric

公开 `instruction.md` 必须明确要求模型重建：

- 核心问题；
- 关键关系和推理路径；
- 决定结论成立的条件与边界；
- 假设、让步、反驳和立场转换；
- 对论证具有构成作用的案例或证据。

但不得把这本书具体有哪些关系、案例、路径和权重列给被测 Agent。

隐藏 Book Card 才包含：

- 核心认知结构；
- 节点角色、立场归属和认识论状态；
- 有方向的最小关系叶子；
- 必需路径与替代路径；
- 构成性案例与说明性案例；
- 原书来源锚点；
- `pass_if`、`fail_if`、常见假阳性和关系反转模式；
- 局部权重及其理由。

## 4. 评分原则

Judge 不直接给整篇文章一个总体印象分。运行流程分成：

1. Evidence Locator 从候选文章中寻找相关引文；
2. Relation Adjudicator 判断目标关系是否被保留；
3. Quote Validator 验证引文存在且没有断章取义；
4. 程序计算关系覆盖和路径完整度。

证据定位和语义判断是两个阶段。Locator 没找到，不自动等同于模型没有表达；正式判缺失前必须执行冻结的二次定位或全文复查规则。

Judge 采用封闭文本重构原则：

- 可以处理同义表达、代词、省略和分散表达；
- 可以连接候选文章已经明确表达的关系；
- 不得用原书知识替候选文章补入缺失前提；
- 不得因为两个概念同时出现，就推断存在因果、支持或反驳关系。

每个关系叶子至少包含：

- 来源节点、目标节点和关系类型；
- 必须保留的方向、机制、条件、边界、立场或案例身份；
- 稳定来源定位和证据摘要；
- 明确的 `pass_if` 与 `fail_if`；
- 可接受的同义表达；
- 常见假阳性和关系反转模式；
- 局部权重和是否关键。

最终结论通常是路径的终点，不在路径之外重复获得一份高权重。只写出最终结论不能获得核心路径分。

## 5. 案例规则

案例分为两类：

### 构成性案例

案例参与作者概念、机制或结论的形成，删除后会改变读者对作者为什么得出该判断的理解。

它必须进入认知结构，标为：

```text
function = constitutive
preservation = required
```

### 说明性案例

案例只帮助解释已经成立的机制或原则。

它可以保留、替换为等价例，或在机制已讲清时省略：

```text
function = illustrative
preservation = replaceable | optional
```

## 6. 结构聚合

对认知结构 `S` 中的关系叶子：

\[
C_S = \frac{\sum_r w_r y_r}{\sum_r w_r}
\]

其中 `y_r` 为二元通过结果，`w_r` 为局部权重。

路径完整度采用严格规则：

- 一条 `mandatory` 路径只有全部关系通过才完整；
- 同一 `alternative_group` 下，至少一条替代路径完整即可；
- 一个认知结构只有所有必需路径和替代组都满足，`path_complete = 1`。

全书先按结构权重计算关系覆盖和完整路径率，再与其他书做宏平均。禁止把所有书的叶子直接池化，否则节点更多的书会获得更高隐含权重。

Pilot 阶段不急于把覆盖分和路径完整率压成一个永久标量。真实模型和受控破坏样本跑完后，再根据区分度与稳定性冻结最终公式。

## 7. 样本范围

V1 正式目标为 5 本书、覆盖至少 3 个非虚构领域，并优先选择认知结构明显不同的作品。一本书对应一道 Harbor Task。

主榜统一固定篇幅。开放篇幅只作为消融实验，用来回答篇幅约束如何改变重构质量。

### 7.1 工程验证

在正式扩展到 5 本书之前：

1. 选择 1 本开发书，用于制作 Rubric、Oracle、Judge Prompt 和校准变体；
2. 开发书允许迭代，但不进入对外主分；
3. 冻结协议后，再选择至少 2 本保留书运行正式 Pilot；
4. 每书每模型默认 3 次 Rollout，主结果报告均值和标准差；
5. `best-of-k` 只作为单独诊断；
6. Pilot 通过后再扩展到 5 本正式书。

每本书的结构和关系数量由内容决定，不以凑够固定节点数为目标。应优先保证：

- 核心结构不被扁平化；
- 关系之间的路径仍可恢复；
- Oracle 在固定篇幅内可以满分；
- 只保留结论、常识替换和关系破坏能够得到明显不同结果。

## 8. 裁判资格考试

资格考试不等于正式样本。它检验评分系统能否识别主动植入的已知缺陷。

最低校准类型：

1. 语义保持改写；
2. 只保留最终结论；
3. 删除一条核心关系；
4. 删除构成性案例；
5. 删除普通说明例；
6. 常识替换；
7. 术语堆砌；
8. 删除限定；
9. 关系反转；
10. 立场归属错误；
11. 改变认知功能的错误重排；
12. 不改变认知功能的正确重组。

至少报告：

- 假阳性；
- 假阴性；
- 关系反转识别；
- 立场误认识别；
- 语义保持改写一致性；
- 关系覆盖变化；
- 路径完整率变化；
- Judge 分歧率。

关键关系反转、立场误认或构成性案例删除仍被判为完整通过时，不得冻结该任务。

## 9. 满分和难度

Benchmark 不要求现有模型得到高分，也不因平均分低而降低标准。

但必须证明：

- 至少一个经审核的 Oracle 可以在规定篇幅内满分；
- 语义等价、组织方式不同的合格重构也能高分；
- 只保留结论不能冒充完整重构；
- 缺失任一必需路径就不能满分；
- 构成性案例缺失会扣除对应结构分；
- 普通说明例替换不会机械失分；
- 正确、错误和破坏样本之间有分辨率。

如果所有真实模型分数都低，这可以是有效结论；如果 Oracle、正确改写和错误版本都同样低，则说明 Rubric 或 Judge 失败。

## 10. 多次 Rollout 与跨书汇总

同一本书的多次 Rollout 使用均值作为主结果，并报告标准差。`best-of-k` 不能代替平均表现。

每本书先得到归一化结果，再跨书宏平均：

\[
S_{benchmark} = \frac{1}{N}\sum_{b=1}^{N}\overline{S_b}
\]

跨模型比较必须冻结：

- Harbor 版本；
- Agent scaffold；
- 系统提示词；
- 工具和文件读取方式；
- 上下文、时间和 token 预算；
- 采样与重试规则；
- 公开 instruction；
- Book Card、Judge 和聚合版本。

若不同模型使用不同 Agent scaffold，结果只能解释为 Agent 系统比较，不能声称只比较基础模型。

## 11. V1 不声称测量什么

- 不声称直接测量文章有没有“灵魂”；
- 不声称检测文本究竟由人还是 AI 写成；
- 不以单一参考文章的表面相似度作为质量；
- 不把语言流畅度等同于读懂了书；
- 不要求模仿作者句式和修辞风格；
- 不把未经校准的 LLM 1–10 分当作金标准；
- 不用单本书结果代表全部非虚构书籍；
- 不声称当前临时 `reward` 已经是最终排行榜公式。
