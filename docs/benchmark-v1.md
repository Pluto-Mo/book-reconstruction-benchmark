# Benchmark V1：基准问题

## 1. 要测量什么

给定一本完整的非虚构作品和固定篇幅，模型能否在高压缩重构中保留该书真正具有区分力的认知结构，而不是把它压缩成正确、流畅、但无信息量的领域常识。

这里的“认知结构”不是关键词覆盖率，而是概念之间的关系：因果、对比、条件、边界、反驳、例证功能与推论方向。

## 2. V1 暂定评分结构

| 维度 | 暂定权重 | V1 操作化方向 |
|---|---:|---|
| 书特异认知结构 | 70% | 每书 8–12 条关系，每条继续拆成可举证的二元原子 |
| 抵抗常识化与空洞化 | 10% | 检测书特异内容是否被领域常识、漂亮空话或主题复述替代 |
| 作者性组织 | 10% | 只测有正反锚点的可观察行为，不直接询问“有几分作者感” |
| 硬约束 | 10% | 字数、文件、格式、任务完成与复制率等程序检查 |

这些权重是待校准假设。若作者性组织无法得到可靠锚点，它应降为诊断指标，而不是强行进入总分。

## 3. 评分原则

裁判模型不直接给文章一个总体分。每个认知原子采用以下流程：

1. 从候选文章引用最短证据；没有证据则返回 `NONE`；
2. 验证引文确实存在于候选文章；
3. 判断证据是否支持该原子；
4. 单独判断文章是否反转或否定该原子；
5. 程序按冻结的权重汇总。

每个书任务的金标准卡至少包含：

- 核心关系概述；
- 稳定来源定位和证据摘要；
- 必须满足的原子条件；
- 可接受的同义表达范围；
- 明确的 `pass_if` 与 `fail_if`；
- 正确但不足以得分的非例子；
- 常见假阳性、误读或关系反转；
- 局部权重及其理由。

## 4. 样本范围

V1 正式目标为 5 本书、覆盖至少 3 个非虚构领域，并优先选择认知结构明显不同的作品。一本书对应一道长任务。

主榜统一固定篇幅。开放篇幅只作为消融实验，用来回答篇幅约束如何改变重构质量。

### 4.1 30 小时工程验证

在正式扩展到 5 本书之前，先完成一个不夸大结论的 Pilot：

1. 选择 1 本开发书，允许用它生成和修改 Rubric、Judge Prompt 与校准变体；
2. 冻结协议后，再选择至少 2 本保留书运行正式 Pilot；
3. 开发书不进入对外主分，避免把调试样本当作泛化结果；
4. 每本书先做 8–12 条核心关系、约 25–40 个有效叶子；
5. 每书每模型默认 3 次 Rollout，主结果报告均值和标准差；
6. Pilot 通过后再扩展到 5 本正式书和更多领域。

一本书可以构成严谨的单任务案例，但不能单独支持“模型一般性非虚构整书理解能力”的结论。

## 5. 裁判资格考试

资格考试不等于正式样本。它检验评分系统能否识别我们主动植入的已知缺陷。

两层校准：

1. **全局资格集**：从代表书制作删除限定、常识替换、关系反转、漂亮空话、纯语言改写等变体，验证裁判总体行为。
2. **每书冒烟测试**：每一本正式书至少制作一例常识化替换和一例关系破坏，验证该书金标准卡没有写坏。

资格样本必须在查看正式模型结果前冻结。资格考试通过，只证明裁判能稳定识别预先定义的错误，不等于它拥有普遍文学审美。

除总体 F1 外，应单独报告假阳性、假阴性、关系反转识别、语义保持改写一致性和 Judge 分歧率。关键关系反转仍被判为通过时，不得冻结该任务。

## 6. 多次 Rollout 与跨书汇总

同一本书的多次 Rollout 使用均值作为主结果，并报告标准差。`best-of-k` 只能作为单独指标。

每本书先按自己的 Rubric 得到归一化根分数，再跨书做宏平均。禁止把所有书的叶子混在一起平均，否则节点较多的书会获得更高的隐含权重。

## 7. V1 不声称测量什么

- 不声称直接测量文章有没有“灵魂”；
- 不声称检测文本究竟由人还是 AI 写成；
- 不以单一参考文章的表面相似度作为质量；
- 不把语言流畅度等同于读懂了书；
- 不把未经校准的 LLM 1–10 分当作金标准；
- 不用单本书结果代表全部非虚构书籍。
