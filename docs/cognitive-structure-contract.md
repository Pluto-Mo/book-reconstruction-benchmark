# 认知结构 Rubric 契约 V1

本文冻结每本书的隐藏 **Book Card** 如何表示。它只定义认知结构维度；独立的篇章关系重构维度见 [篇章关系重构评分契约](discourse-reconstruction-contract.md)。

## 1. 第一性目标

认知结构维度测量：

> 给定完整非虚构作品与固定篇幅，模型能否重建作者形成判断时使用的书特异问题、命题关系、推理路径、条件边界、立场转换与关键论证材料，而不是只得到正确但普通的最终结论。

它不是关键词集合，也不是观点数量。它至少包含：

- 作者试图解决的核心问题；
- 命题、概念、案例和证据分别承担什么角色；
- 谁持有某个观点，以及作者是提出、假设、让步、限定还是推翻它；
- 因果、支持、反驳、区分、条件、边界和推论如何连接；
- 哪些关系共同构成不可省略的核心路径；
- 哪些案例参与了结论形成，而不只是帮助说明。

## 2. 阅读效用动机

本项目的现实目的，是让读者通过 AI 高压缩结果获得一本书真正独有的认知价值，而不是只得到主题正确的摘要。项目仍沿用以下阅读动机：

- 《如何阅读一本书》：保留全书骨架、关键概念、命题和论证；
- 《刻意练习》（安德斯·埃里克森）：形成可用于识别、解释和纠错的心理表征；
- 《实用性阅读指南》：使知识可以被回忆、输出和用于行动；
- 《深度阅读》：压缩不是均匀缩短，而是识别高价值内容并重新组织。

这些思想只定义 Benchmark 的人类阅读目标，不替代每本正式书自己的 Book Card。

“读完 submission 后是否更容易迁移和应用”仍属于后续效度验证，V1 不把它凭印象混入认知主分。

## 3. 与篇章关系重构的边界

认知维度只问内容关系是否正确保留。

若某种顺序、让步或反驳方式会改变观点归属、推理方向、条件边界或认知功能，它仍属于认知结构。例如把作者正在反驳的观点写成作者主张，是认知错误。

新的篇章关系维度另问：

- 正确内容是否继续承担原书中的全书层级和修辞功能；
- 候选文章的后续部分是否实际使用前面建立的关系；
- 重新组织后是否形成真实文章推进。

同一语义关系在篇章维度只作为内容门槛，不重复奖励。

纯句式、节奏、修辞模仿和作者身份识别不属于两个 V1 主维度。

## 4. 公开任务与隐藏 Book Card

公开 `instruction.md` 必须说明：

- 需要理解一本书最独特的判断与推理；
- 需要写成面向真实读者的独立文章；
- 允许重新组织材料；
- 不得逐章摘要、观点罗列或大段摘抄。

公开任务不得列出本书具体关系、案例、路径、权重或隐藏校准项。

隐藏 Book Card 保存：

```text
Book
└── Cognitive Structure
    ├── Nodes
    ├── Typed Relations
    └── Required / Alternative Paths
```

## 5. 节点

节点表示参与作者思考过程的内容单元，例如：

- 问题；
- 作者主张；
- 对手观点；
- 暂时假设；
- 前提；
- 机制；
- 条件与边界；
- 证据、案例或反例；
- 反驳与结论；
- 推论或行动原则。

节点本身通常不单独得分。每个节点至少记录：

- `role`：论证角色；
- `stance_owner`：作者、对手、引用来源、假设主体或中性材料；
- `epistemic_status`：主张、假设、让步、否定、限定、保留或观察；
- `source_anchor_ids`；
- `essential`。

## 6. 最小评分叶子是有方向关系

“认知原子”严格定义为：

> 最小、可独立判定、具有方向和语义类型的关系。

例如：

```text
反例 E --refutes--> 假设 H
机制 M --supports--> 结论 T
条件 C --qualifies--> 结论 T
概念 A --distinguishes--> 概念 B
前提 P1 + P2 --jointly_supports--> 结论 T
```

关系必须留在所属结构和路径中，不能拆完后作为无结构叶子池。

一条关系只有同时满足以下条件才可成为 Judge 叶子：

1. 来源和目标节点明确；
2. 方向和关系类型明确；
3. 只要求一次窄语义判断；
4. 必须保留的机制、条件、边界、立场或案例身份写入 `required_facets`；
5. 候选文章可以直接取证；
6. Judge 不需要用原书补入缺失前提；
7. 有 `pass_if`、`fail_if` 和常见假阳性；
8. 有原书 Source Anchor；
9. 允许语义等价表达；
10. 仍附着在路径中。

## 7. 图和路径

认知结构允许：

- 线性因果链；
- 多前提汇合；
- 分支与替代路径；
- 假设—让步—反驳；
- 案例归纳后由反例限定；
- 概念区分后推出不同结论。

`mandatory` 路径全部关系通过才完整。

多个等价论证路径可以放在同一 `alternative_group`；至少一条完整即可。

所有关键关系必须进入至少一条路径。

## 8. 顺序规则

本维度不要求机械复刻原书章节顺序。

判断标准：

> 改变顺序后，是否改变观点归属、推理方向、条件边界或构成性材料的认知功能？

- 若改变，相关认知关系和路径必须体现；
- 若不改变，候选文章允许自由重组；
- 文章重组后的阅读推进质量由篇章关系维度判断。

因此：

```text
错误重排导致认知功能变化
→ 认知结构扣分

内容关系仍正确，但文章变成可任意交换的模块
→ 认知分可保持，篇章关系分下降
```

## 9. 案例

### 9.1 构成性案例

案例推翻关键假设、引出机制、建立概念区分，或是作者结论不可替代的事实基础时：

```text
function = constitutive
preservation = required
```

它必须保留身份与认知功能。

### 9.2 说明性案例

只帮助理解已成立机制时：

```text
function = illustrative
preservation = replaceable | optional
```

不因未复述全部故事机械扣分。

候选文章如何把保留的案例嵌入新文章，属于 `example_integration`，在篇章关系维度评分。

## 10. 最终结论不重复计分

若原书结构是：

```text
假设 H → 反例 E → 机制 M → 限定 C → 结论 T
```

只写 `T`：

- 不能获得核心路径分；
- 不能因结论正确而重复计分；
- 若所有模型都能写出 T，T 只保留为基本有效性检查。

## 11. 封闭文本重构原则

允许 Judge：

- 识别同义表达；
- 解析代词和省略；
- 连接候选文章中分散但明确表达的关系；
- 识别让步、反驳和限定；
- 接受不改变认知功能的重排。

禁止 Judge：

- 用原书知识补入候选文章缺失的实质性前提；
- 因两个概念共同出现就推断存在因果或支持；
- 把模糊表达自动解释成正确立场；
- 用原书桥接命题填补候选推理缺口。

## 12. 三类证据

- `source_anchor`：证明 Rubric 来自原书；
- `argument_evidence`：作者用来支持、解释或反驳的材料；
- `submission_evidence`：候选文章中的运行时引文。

运行时：

```text
Evidence Locator
→ Relation Adjudicator
→ Quote Validator
→ Graph Aggregator
```

第一次定位失败不得直接作为模型语义失败；必须执行冻结的二次定位或全文复查。

## 13. 计分

### 13.1 关系覆盖

\[
C_S = \frac{\sum_r w_r y_r}{\sum_r w_r}
\]

### 13.2 核心路径完整率

一条必需路径只有全部关系通过才完整；替代组至少一条完整。

全书报告：

```json
{
  "cognitive_relation_coverage": 0.68,
  "complete_core_path_rate": 0.31
}
```

Pilot 不把二者武断压成永久单一认知分。

## 14. 满分、难度和可达性

Benchmark 不需要为了让现有模型得到高分而降低标准，但每个正式 Task 必须满足：

- 经审核 Oracle 可以在规定篇幅内满足全部必需认知结构；
- 语义等价、组织方式不同的忠实重构也能达到高分；
- 只保留最终结论会显著降分；
- 删除一条关键关系会使所属路径失败；
- 删除构成性案例会失去对应关系和路径分；
- 删除普通说明例原则上不会机械扣分；
- 关系反转、限定删除和立场误认可以被稳定识别；
- 正确、错误和受控破坏样本形成可区分分布。

“所有模型都低分”可以是有效结果；“Oracle、正确改写和错误破坏样本都得到相似低分”说明 Rubric 或 Judge 没有分辨率。

## 15. 制作每个认知结构时必须回答的问题

Builder、Auditor 和 Human Owner 对每个候选结构回答：

1. 作者在这里试图解决的具体问题是什么？
2. 哪些节点是作者主张，哪些是对手观点、假设、让步或被否定观点？
3. 哪些最小有方向关系共同形成作者判断？
4. 删除哪些条件、边界或否定范围会把判断压成普通口号？
5. 哪些关系必须共同存在，才算恢复完整核心路径？
6. 是否存在多条等价论证路径，哪些可以替代？
7. 哪些案例是构成性的，哪些只是说明性的？
8. 哪些顺序变化会改变认知功能，哪些只是表达重组？
9. 一个只知道领域常识、没有读过本书的人会写出什么看似正确但不足的版本？
10. 只写最终结论时，具体缺失了哪些关系？
11. 每条关系能否从原书定位，并从候选文章独立取证？
12. Oracle 能否在固定篇幅内同时满足全部必需路径？

任何问题没有清楚答案，该结构保持 `draft`，不得冻结。

## 16. 校准

最低包含：

- 语义保持改写；
- 不改变认知功能的正确重组；
- 只保留最终结论；
- 删除核心关系；
- 删除构成性案例；
- 删除说明性案例；
- 常识替换；
- 术语堆砌；
- 删除限定；
- 关系反转；
- 立场误认；
- 改变认知功能的错误重排。

章节交换、模块化和通用结尾等仅损伤篇章关系的扰动，见 Discourse Card；它们原则上不应被认知 Judge 无差别扣分。

## 17. 冻结项

本文件冻结：

- 认知对象是关系图和路径，不是扁平观点列表；
- 最小认知评分叶子是有方向关系；
- 节点保存角色、立场和认识论状态；
- 构成性案例进入认知结构；
- 最终结论不重复计分；
- 公开任务与隐藏 Book Card 分离；
- Pilot 并列报告关系覆盖和路径完整；
- 认知维度与篇章关系维度独立，内容正确性不在篇章维度重复奖励。

暂不冻结：

- 两个认知指标如何合成；
- 认知结构与篇章关系重构如何合成最终排行榜分数；
- 关系反转是否使用负分；
- Judge 最终状态机；
- 每本书的结构、关系和路径数量；
- 具体书目、权重和正式金标准。
